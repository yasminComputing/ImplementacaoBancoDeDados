# Regras Gerais 
- Sem espaço ou caracteres especiais: não utilizar espaços, acentos, hifens. Para separar as palavras utilizar `PascalCase` ou `snake_case`.
- Evitar palavras-chaves: nunca nomear um objeto com uma palavra reservada do SQL, como `SELECT`, `TABLE`.
- Em tabelas: recomendado usar `PascalCase` no `Singular`.
  
# Revisão dos conceitos/prática do SQL
- Modelo Entidade Relacionamento Conceitual:
  - Usado retângulo: pode representar algo do mundo real ou abstrato
  - Relação: a palavra `relação` têm significado de tabela
  - Toda entidade necessita de uma `chave-primária`
  - Atributo composto: quando têm outros atributos. Exemplo: endereço contém (rua, numero, cep, complemento) e que está ligada `Funcionário`.
  - No atributo pode ser (1,N) que significa que pode conter um para muitos. 

> Principal motivo do uso de banco de dados invés do Excel é a integração de não ter **duplicidade**, pois cada dado tem que conter um índice que o identifique.
